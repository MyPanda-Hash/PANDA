> 真实 T+：ST1024 其他出库单（h4t.chanjet.com 机械行业账套）。

## 1. 真实「选单」子项（topText 全名）

```
选单 / 要货单 / 配货单 / 设置默认功能
```

- **要货单**：配货业务源头单据（部门/门店提需）。
- **配货单**：配货业务配送单据（按要货单生成）。
- 链路：要货单 → 配货单 → 出库（其他出库单/销售出库单）。本面板选单即从这两张已审核单据拉取。

## 2. 源单据面板 vs 轻MES 现有面板

| 源单据 | 轻MES 现有面板 | 结论 |
|---|---|---|
| 要货单 | 无（menus.js / engine.js 均无） | **需新增面板**：建议 panelCode `DEMAND_ORDER`，名称「要货单」 |
| 配货单 | 无 | **需新增面板**：建议 panelCode `DISTRIBUTION_ORDER`，名称「配货单」 |

> 轻MES 现有 6 张库存单据 + 生产/销售链路均无 配货业务单据；选单按钮在源面板缺失前保留在工具栏（点击提示演示环境未实现），或先按主源（要货单）接入 selectConfig 骨架。

### 2.1 需新增面板理由

1. **要货单（DEMAND_ORDER）**：真实选单第一子项，T+ 配货业务源头；字段预计：单据日期/单据编号*/业务类型/部门/经手人/往来单位/存货名称/数量/计量单位/需求日期/备注 等（本期未抓取，二期按 T+ SC 系单据抓取对齐）。
2. **配货单（DISTRIBUTION_ORDER）**：真实选单第二子项；由要货单流转生成（可配 selectConfig: source=DEMAND_ORDER），字段预计：单据日期/单据编号*/业务类型/配货仓库/往来单位/存货名称/数量/计量单位 等。

## 3. 轻MES selectConfig 建议（参考 SALE_OUT→SO_ORDER / MATERIAL_OUT→MANU_ORDER 结构）

选单前提对齐 T+：仅已审核且未中止。当前轻MES selectConfig 为**单源**结构，建议**主源=要货单**：

```json
{
  "source": "DEMAND_ORDER",
  "title": "选要货单",
  "tip": "仅显示已审核且未中止的要货单，选中后明细带入其他出库单（对齐 T+ 选单前提）",
  "columns": ["单据编号", "单据日期", "往来单位", "部门", "经手人", "存货名称", "数量", "计量单位"],
  "headerMap": [
    { "from": "单据编号", "to": "来源单据" },
    { "from": "往来单位", "to": "往来单位" },
    { "from": "部门", "to": "部门" },
    { "from": "经手人", "to": "经手人" }
  ],
  "detailMap": [
    { "from": "存货名称", "to": "存货名称" },
    { "from": "存货编码", "to": "存货编码" },
    { "from": "规格型号", "to": "规格型号" },
    { "from": "计量单位", "to": "计量单位" },
    { "from": "数量", "to": "数量" }
  ],
  "sourceNoField": "来源单号"
}
```

> 字段映射为建议值：要货单表头/明细字段以二期新增面板（DEMAND_ORDER）实际配置为准，合并时按「from 字段存在性」校验。
> **配货单第二源**：`DISTRIBUTION_ORDER` 面板新增后，选单组第二 action「选配货单」可再挂 selectConfig（或引擎后续支持多源）。headerMap/detailMap 同构（配货仓库→明细仓库）。

## 4. 关联按钮组

| 组 | 子项 | 目标/处理 |
|---|---|---|
| 转换 | 转换成其他入库单 | OTHER_IN 面板已存在 → 可推式转换（callButton 分支） |
| 转换 | 转换成销货单 | 轻MES SALE_OUT=销售出库单（≈T+ 销货单）→ 可映射转换，未实现前保留按钮 |
| 转换 | 生成凭证 | 财务凭证，未实现，保留按钮（UNIMPLEMENTED 提示） |
| 工具 | 配比出库/拣货/盘点情况/组装拆卸情况/形态转换情况/出库调整情况/凭证情况/配货情况/要货情况 | 未实现，保留按钮 |

## 5. 结论

- 真实选单源单据：**要货单、配货单**（非采购/销售/生产加工类单据）。
- 轻MES 两源均缺失 → **需新增面板：要货单（DEMAND_ORDER）、配货单（DISTRIBUTION_ORDER）**。
- 本面板 selectConfig 先按主源=要货单（DEMAND_ORDER）落地骨架；选单组动作保留「选要货单/选配货单」，源面板未建时点击提示演示环境未实现。
