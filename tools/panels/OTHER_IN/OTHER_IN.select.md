# OTHER_IN 其他入库单 — 选单按钮专项分析

> 依据：`docs/ref/tplus-live/mech-20260819/st/other_in.dom.json`（topText 含「选单」下拉全名）、`other_in-new-form.json`（header 含「选单」菜单文本）
> 对照：《面板交互设计规范》§3.3 拉式选单弹窗、§10 单据流转（选单/生单）标准

## 一、真实「选单」按钮子项（机械账套 h4t，2026-08-19 抓取）

topText / new-form header 原文片段：
`…选单 / 其他出库单 / 设置默认功能 / 其他出库单 / 智能选单 / 保存…`

| 子项 | 类型 | 说明 |
|---|---|---|
| 其他出库单 | 源单据（拉式选单） | 从已审核的其他出库单选单，红冲/退库转其他入库 |
| 智能选单 | 通用智能选单 | T+ 企业版智能匹配功能，非面板级 |

> 注：本账套「选单」**没有** 采购订单/销售订单/生产加工单/工序汇报单/进货单 等子项（与任务示例不同——机械行业此账套其他入库单的选单源只有 其他出库单 + 智能选单）。

## 二、选单源单据 → 轻MES 面板映射

| 真实选单源 | 轻MES 面板 | 存在性 | 说明 |
|---|---|---|---|
| 其他出库单 | OTHER_OUT（其他出库单） | ✅ 已存在（engine.js L975） | 无需新增面板 |
| 智能选单 | — | ⚠️ 功能未实现 | 保留按钮，点击 UNIMPLEMENTED 提示 |

→ **本面板选单无缺失面板**；missingPanels 为空（选单维度）。

## 三、轻MES selectConfig 建议

结构参考现有配置（SALE_OUT L804-822、FINISH_IN L676-691、PROCESS_REPORT L1224-1276 的 selectPanel/columns/headerMap/detailMap/sourceNoField/detailRows 模式）。OTHER_OUT 表头含 仓库/来料客户（真实 other_out 抓取含 部门/经手人/项目/往来单位），明细含 仓库/存货名称/规格型号/计量单位/数量/单价/金额/现存量——两单字段同构，可直带明细。

```js
selectConfig: {
  source: 'OTHER_OUT',
  title: '选其他出库单',
  tip: '仅显示已审核且未中止的其他出库单，选中后明细带入其他入库单（对齐 T+ 选单前提：已审核且未中止）',
  columns: ['单据编号', '单据日期', '业务类型', '仓库', '往来单位', '存货名称', '存货编码', '数量', '计量单位', '单价', '金额'],
  headerMap: [
    { from: '单据编号', to: '匹配来源单号' },
    { from: '仓库', to: '仓库' },
    { from: '往来单位', to: '往来单位' },
  ],
  detailMap: [
    { from: '仓库', to: '仓库' },
    { from: '存货名称', to: '存货名称' },
    { from: '存货编码', to: '存货编码' },
    { from: '规格型号', to: '规格型号' },
    { from: '计量单位', to: '计量单位' },
    { from: '数量', to: '数量' },
    { from: '单价', to: '单价' },
    { from: '金额', to: '金额' },
    { from: '现存量', to: '现存量' },
  ],
  sourceNoField: '匹配来源单号',
}
```

要点：
- `sourceNoField: '匹配来源单号'` → 表头保留「匹配来源单号」字段作为来源单号落点（见 design.md 2.1 建议保留项）。
- 选单前提：来源单 单据状态=已审核 且未中止（§10.2，选单弹窗查询条件固定 `{单据状态:'已审核'}`）。
- 无需 `detailRows`（OTHER_OUT 明细即平铺 items，直接 detailMap 带出）。
- 合并时同时把 selectConfig 挂到 `getFormDescriptor`/`getNewFormPermMatrix` 返回（§16 表单页选单可用性）。

## 四、工具栏「转换」组的目标面板缺口（关联）

真实「转换」子项：转换成进货单、转换成销货单、转换成其他出库单。

| 转换目标 | 轻MES 对应 | 说明 |
|---|---|---|
| 转换成其他出库单 | OTHER_OUT ✅ 存在 | 可落地 |
| 转换成进货单 | ❌ 缺失 | T+「进货单」是采购业务单据，轻MES 现有 采购入库单(PURCHASE_IN) 与其语义不同 → **需新增面板 进货单**（或暂未实现占位） |
| 转换成销货单 | ❌ 缺失 | T+「销货单」是销售业务单据，轻MES 现有 销售出库单(SALE_OUT) 与其语义不同 → **需新增面板 销货单**（或暂未实现占位） |

## 五、结论
- selectSources：['OTHER_OUT']（真实选单源，已存在）
- missingPanels（本面板选单）：无；扩展视野（转换目标）：['进货单', '销货单']（非选单必需，合并时按需决定落地或 UNIMPLEMENTED 占位）
- 智能选单：保留按钮 + UNIMPLEMENTED 提示（界面与 T+ 保持一致）
