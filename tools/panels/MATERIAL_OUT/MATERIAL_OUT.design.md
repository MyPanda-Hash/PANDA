## 一、真实 T+ 面板结构提取

## 四、需新增面板清单

1. **工序派工单（DISPATCH_ORDER）**：真实选单子项「选工序派工单」；轻MES 现仅有工序汇报（PROCESS_REPORT/REWORK_REPORT），无派工单 → 材料出库无法按派工单领料。
2. **领料申请单（MATERIAL_REQ）**：真实选单子项「选领料申请单」；MO 表头已有「启用领料申请」字段说明该环节真实存在 → 轻MES 缺面板，材料出库无法从领料申请单选单。

## 五、新配置要点汇总（供主会话合并）

- header：见 `MATERIAL_OUT.header.json`（10 字段，顺序对齐真实；`today` 占位符合并时替换为引擎 `today` 变量）。
- buttonGroups：见 `MATERIAL_OUT.toolbar.json`（19 组，真实顺序 + 任务规定基础组；未实现按钮保留）。
- detail.tabs[0].fields：表头同批改造为 参照 INV/WH/PROJ + 新增 材料编码/项目/产品名称/数量2/生产日期/批号/来源单据/来源单号/可用量，规格型号降隐藏、明细备注移除、现存量说明隐藏；calc 保持 金额=数量×单价，新增 可用量 computed。
- gridColumns（A 区可见列）：材料编码 → 项目 → 产品名称 → 加工单号 → 材料名称 → 计量单位 → 仓库 → 数量 → 数量2 → 金额 → 单价 → 手工确定成本 → 生产日期 → 批号 → 来源单据 → 来源单号 → 可用量 → 现存量（对齐真实 1.4 可见列顺序）。
- sumColumns（汇总页签）：仓库 / 材料编码 / 材料名称 / 规格型号 / 计量单位 / 数量 / 单价 / 金额。
- selectConfig：见 `MATERIAL_OUT.select.md`。
- 编号前缀沿用 `MD-`（INV_PREFIX 已注册）。
- 表尾字段不变（制单人/审核人/审核日期/审核时间/打印次数/创建时间）。

## 六、抓取说明与局限

- topText 在「生成材料出库」处截断（抓取工具限制），生单子项按 T+ 语义与现有配置补全为 直接退料/自制退料。
- 真实「审核/弃审/审批情况」为分列按钮，轻MES 按审批流规范合并为审核组（§8.4 已定稿，10 单据面板统一）。
- 真实 版本号/自由项/货位子表 属 T+ 自由项与货位功能，轻MES 暂不承载（预留）。
