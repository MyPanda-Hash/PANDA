### 2.3 detail.tabs[0].fields（18 个明细字段，key=items）
存货编码*（参照 INV）/ 存货名称*（参照 INV，refMap 带出 编码/规格/销售单位）/ 规格型号（文本）/ 仓库*（参照 WH，默认 成品仓）/ 项目（参照 PROJ）/ 数量*（小数）/ 销售单位*（下拉框 件/kg/套/升）/ 批号（文本）/ 现存量（computed）/ 销售单位结存成本（小数）/ 税率%（小数，默认 13）/ 单价*（小数）/ 含税单价（computed）/ 金额（computed）/ 税额（computed）/ 含税金额（computed）/ 折扣%（小数，默认 0）/ 折扣金额（computed）。

**calc 计算链**（金额 computed + calc 链，对齐真实 T+ 价税分离）：
```
含税单价 = 单价 * (1 + 税率% / 100)
金额     = 数量 * 单价
税额     = 数量 * (含税单价 - 单价)
含税金额 = 金额 + 税额
折扣金额 = 金额 * 折扣% / 100
```
summaryItems：数量合计 / 金额合计 / 含税金额合计。
