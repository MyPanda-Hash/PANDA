## 二、配置设计（对齐 PU_ORDER_CONFIG 结构）

| 配置段 | 数量 | 说明 |
|---|---|---|
| `queryFields` | 6 | 单据日期/单据编号/业务类型(下拉 配货出库,调拨出库)/客户(参照 PARTNER)/项目(参照 PROJ)/出库仓库(参照 WH) |
| `gridTabs[0]` 明细 | 16 列 | 真实可见列前 16 个（至 可用量），rowSource=items |
| `gridTabs[1]` 汇总 | 7 列 | 按存货分组：存货编码/存货名称/规格型号/计量单位/数量/零售价/零售金额，summary:true |
| `dataSchema.fields` | 12 | 单据日期*/单据编号*(autoCode)/业务类型* + 客户/客户编码/出库仓库/入库仓库/经手人/项目/部门/预计交货日期/备注 |
| `detail.tabs[0].fields` | 18 | key=items；客户(参照 PARTNER)/存货编码(参照 INV，带出名称/规格/单位)/名称/规格/计量单位/数量/零售价/零售金额(computed)/出库仓库/入库仓库(参照 WH)/累计出库·调拨·入库数量/合理损耗数量/预计交货日期/可用量(computed)/现存量/是否带票 |
| `detail.tabs[0].calc` | 2 | 零售金额 = 数量 × 零售价；可用量 = 现存量 − 数量 |
| `summaryItems` | 2 | 数量合计 / 零售金额合计 |
| `formPages` | 1 | 表头 12 字段 + 底部 保存/删除/审核/弃审/放弃 |
| `panelButtons` | 7 | 新增/删除/刷新/保存/审核/弃审/放弃 |
| `buttonGroups` | 14 | 见下 |

### 参照化（开发约束十一-1）
- 供应商/客户 → `PARTNER`（往来单位名称；refMap 带出 客户编码）
- 经手人 → `EMP`、项目 → `PROJ`、仓库 → `WH`、部门 → `DEPT`、存货物料 → `INV`（refMap 带出 存货名称/规格型号/计量单位）
- 下拉选项均为字面量：业务类型 `['配货出库','调拨出库']`、计量单位 `['件','kg','套','升']`、是否带票 `['带票','不带票']`

### buttonGroups（14 组，对齐真实工具栏 + 页面开发规范）
新增(引入常用单据,设置默认功能) / 选单(选要货单,选销售订单,选销货单,设置默认功能) / 修改 / 保存(保存新增,保存为草稿,保存打印,设置默认功能) /
删除(删除单据) / 审核(弃审) / 生单(生成调拨单,生成销售出库单,生成其他出库单(调拨出库),生成其他出库单(配货出库),设置默认功能) / 变更 /
查找(刷新) / 工具(12 项全名) / 设置 / 打印 / 导入(下载导入模板,导入) / 更多(复制,导出,退出)
未实现动作全部保留，点击走 `engine.UNIMPLEMENTED`（「演示环境暂未实现，界面与 T+ 保持一致」）。

## 四、主会话合并清单（勿在本次交付内执行）

1. **注册 panelOf**：`if (panelCode === 'PICK_ORDER') return { config: PICK_ORDER_CONFIG, rows: PICK_ORDER_ROWS }`
2. **编号前缀登记**：`PxService.generateFormNo` 增加 `PICK_ORDER` → `PH-`（拟用前缀，格式 PH-yyyy-MM-dd+2 位日序，规范 §9）；本文件行内 `编号` 即该格式
3. **审批流**：配货单 状态机为 草稿/已审核/已中止，未加入 `APPROVAL_PANELS`（工具栏 审核 组仅 审核/弃审，符合 T+ 实测）
4. **选单 selectConfig（可选）**：真实 选单 来源为 要货单/销售订单/销货单（后两者对应 SO_ORDER），如需可拉式选单按 交互规范 §10.3 补 `selectConfig`（source:'SO_ORDER'，headerMap/detailMap 映射 客户/存货编码/存货名称/规格型号/计量单位/数量/零售价），未配置时「选单」点击走未实现提示
5. 生单 跳转目标面板（调拨单/销售出库单/其他出库单）接入 `callButton` 分支后按 §10.5 返回 `{gotoPanel, 编号}`

## 五、差异与取舍

- 真实查询区 8 字段 → 取 6 个高频字段（保留 业务类型/客户/项目/出库仓库，客户编码 移入表头 dataSchema）
- 网格取真实可见列前 16 个（至 可用量）；现存量/现存量说明/是否带票 等在明细字段中提供（现存量说明 与 数量客户规格 未入明细字段，避免超出 18 字段上限）
- 单据状态按需求 草稿/已审核/已中止（真实 T+ 含 审批中 由审批流面板承担）
