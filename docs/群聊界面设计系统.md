# 项目群聊界面 · 设计系统（Ant Design v6.6.8）

> 适用：`frontend-group/index.html` + `app.js` + `app.css`（AI 数字员工的项目群聊页）。
> 设计库：`~/.dsh/design-kits/antd`（antdVersion 6.6.8），取值为 `dsh-kit token` 实查结果。

## 1. 骨架

三栏工作界面（不是营销页）：

```
┌ topbar 48 ─────────────────────────────────────────────┐
│ ← 返回   项目群聊                      铃铛 · 账号菜单   │
├ 左侧 264 ┬ 中间自适应 ────────────────┬ 右侧 300 ───────┤
│ 我的项目群│ 群头 56（头像/名称/成员数）  │ 成员 / 我的待办  │
│ 群列表    │ 消息流（气泡 8px 圆角）      │ 列表（1px 分隔）  │
│          │ 输入区（focus 主色描边）      │                 │
└──────────┴─────────────────────────────┴─────────────────┘
```

断点：≥1025 三栏 / 901–1024 两栏 / ≤900 右栏收抽屉 / ≤640 单栏（群切换改下拉）。

## 2. 数值（token 全部来自设计库）

| 用途 | token | 明色 | 暗色 |
|---|---|---|---|
| 主色 | `colorPrimary` | `#1677ff` | `#1668dc` |
| 主色 hover / active | `colorPrimaryHover` / `colorPrimaryActive` | `#4096ff` / `#0958d9` | `#3c89e8` / `#1554ad` |
| 主色浅底 / 描边 | `colorPrimaryBg` / `colorPrimaryBorder` | `#e6f4ff` / `#91caff` | `#15325b` / `#15325b` |
| 容器 / 布局底 | `colorBgContainer` / `colorBgLayout` | `#ffffff` / `#f5f5f5` | `#141414` / `#000000` |
| 边框 / 次边框 | `colorBorder` / `colorBorderSecondary` | `#d9d9d9` / `#f0f0f0` | `#424242` / `#303030` |
| 文字 1/2/3 级 | `colorText` / `colorTextSecondary` / `colorTextTertiary` | `rgba(0,0,0,.88/.65/.45)` | `rgba(255,255,255,.85/.65/.45)` |
| 浅填充 | `colorFillAlter` / `colorFillTertiary` | `rgba(0,0,0,.02/.04)` | `rgba(255,255,255,.04/.08)` |
| 圆角 | `borderRadius` / `borderRadiusLG` | `6px` / `8px` | 同左 |
| 控件高 | `controlHeight` / `controlHeightSM` | `32px` / `24px` | 同左 |
| 字号 / 行高 | `fontSize` / `lineHeight` | `14px` / `22px`（1.5715） | 同左 |
| 浮层阴影 | `boxShadowSecondary` | `0 6px 16px rgba(0,0,0,.08)…` | 加深版 |

实现方式：`app.css` 顶部把上表写成 `--ant-color-*` 变量，再映射到旧语义变量
（`--bg/--panel/--line/--ink/--accent/--radius`），**393 条既有选择器自动继承新视觉**，
不必逐条重写；明暗两套只换 token 值。

## 3. 组件对应

| 界面元素 | 设计库组件 | 采用的关键属性 |
|---|---|---|
| 主操作（AI 整理待办 / 发送） | Button | `type="primary"`、`height 32`、`radius 6`、同区唯一主按钮 |
| 次级操作（邀请成员 / 新建） | Button | 默认（白底 + `colorBorder` 描边），hover 主色描边 |
| 群列表 | Menu（inline） | 选中项 `colorPrimaryBg` + 左侧 2px 主色条，不用整块描边 |
| 未读 / 待办计数 | Badge | 18px 高、`border-radius 10px`、`tabular-nums` |
| 成员角色、群标签 | Tag | `radius 4`、`colorFillAlter` 底、12px 字 |
| 右侧「成员 / 我的待办」 | Tabs | 下划线式：选中主色 + 2px 底边，高度 48 |
| 消息气泡 | （antd 无聊天组件，按 Card/Comment 的 0 层规则）| 1px `colorBorderSecondary` 边框、`radius 8`、无阴影、最大宽 640 |
| 输入区 | Input.TextArea | 聚焦时主色描边 + `0 0 0 3px rgba(22,119,255,.12)` 光环 |
| 弹窗 | Modal | `radius 8` + `boxShadowSecondary` + 1px 边框 |

参考实现（设计库源码，未改结构只改数据）：

## 4. 硬规则落地

1. 卡片 0 层用 1px 边框，不叠阴影；只有弹窗/浮层用 `boxShadowSecondary`。
2. 8pt 网格：栏间距 8、面板内边距 12/16/24。
3. 控件高 32、圆角 6（容器 8）、正文 14/22。
4. 同一操作区只有一个主按钮（群头是「AI 整理待办」，输入区是「发送」）。
5. 时间、计数、序号一律 `font-variant-numeric: tabular-nums`。
6. 空态给下一步（「还没有项目群 → 新建」）。
7. 不用装饰渐变、不用大色块填充、不卡片套卡片。

## 6. 已知限制

- 「项目群」下拉在 ≤640 用原生 `<select>`：Chrome 对其 `height` 不生效（实测 `height:32px` 与
  `!important` 都被 UA 控件盒覆盖），改用 `padding 6px + font 14px` 得到 32px 观感。
- 消息气泡是自绘（设计库没有聊天组件），只借用 Card / Comment 的层级与间距规则。
## 7. 气泡前景色规则（2026-11-13 修正）

**规则：气泡的前景色跟着自己的底色走，不能按「谁发的」写死。**

| 气泡 | 底色 | 前景 |
|---|---|---|
| 我的（`.msg-row--mine .bubble`） | `colorPrimaryBg`（明 `#e6f4ff` / 暗 `#15325b`） | `colorText`（明 `rgba(0,0,0,.88)` / 暗 `rgba(255,255,255,.85)`） |
| AI / 他人（`.bubble`） | `colorBgContainer` + 1px `colorBorderSecondary` | `colorText` |
| 回执「未读/已读」 | 跟随气泡 | `colorTextTertiary`，已读用 `colorPrimary` |
| 引文条 | `colorFillTertiary` | `colorTextSecondary` |

踩过的坑：旧规则把「我的气泡」写成 `background: var(--accent); color: #fff`（微信绿底白字）。
设计库升级只换了底色（改成浅蓝）没换前景色，结果**浅色主题下白字压在浅蓝底上几乎看不见**。
现在已删掉那条旧规则，前景色统一在设计库层用 token 定义；实测明色 `rgba(0,0,0,.88) / #e6f4ff`，
暗色 `rgba(255,255,255,.85) / #15325b`。

## 8. 头像与个人设置（2026-11-14）

### 能改什么

右上角账号菜单 → **个人设置**：

| 项 | 交互 | 落点 |
|---|---|---|
| 头像 | 上传（PNG/JPG/WEBP/GIF/BMP，≤5MB）、移除 | `backend/uploads/avatars/<user_id>.png`（居中裁切 256×256） |
| 昵称 | 输入 + 保存/回车 | `users.display_name`（`PATCH /api/auth/display-name`） |
| 外观 | 浅色 / 深色 / 跟随系统 | `localStorage.dnx-theme` + `:root[data-theme]` |
| 消息字号 | 小 13 / 标准 14 / 大 16 | `localStorage.dnx-chat-font` → `--chat-font`，只影响正文与输入框 |

### 为什么头像不进数据库

「有没有头像」= 文件在不在，「换没换」= 文件 mtime。省一次迁移，换头像立刻生效：

- `POST /api/auth/avatar` → PIL 校验格式、居中裁成 256×256 PNG 落盘，返回 `avatar_url`
- `DELETE /api/auth/avatar` → 删文件
- `GET /api/users/{id}/avatar` → `FileResponse` + `Cache-Control: private, no-cache` + `ETag`（mtime）
- `/api/auth/me`、群成员、群消息三处响应都带 `avatar_url` / `sender_avatar_url`

### 前端渲染约定

所有头像走同一个 `avatarNode(className, name, url, { ai })`：

- 有 `avatar_url` → `<img loading="lazy">`，加载失败自动回退姓名首字
- AI 助手恒为 `AI` 字样（不走图片）
- 顶栏 24px、消息/成员 28px、设置面板预览 64px，圆角统一 6（容器）/ 8（预览）

### 鉴权注意

群聊页是 **cookie 会话**，聊天页是 **Bearer**。头像与昵称两个接口都改成
`current_user_from_bearer_or_cookie`，否则群聊页里点保存会 401（踩过）。
