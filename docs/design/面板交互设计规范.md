# 轻MES 面板交互设计规范（点击填写 / 弹窗 / 选单）

> 2026-08-14 定稿。本规范定义轻MES 所有单据面板（Panelx 体系）的交互行为标准，
> 后续新增设计面板（库存报表/账表/其他模块）一律沿用本规范，不再各自实现。

## 1. 面板形态总览

| 形态 | 路由 | 组件 | 用途 |
|---|---|---|---|
| 单据列表 | `/panelx/list/:panelCode` | PanelxList.vue | 查询区 + 工具栏 + 明细/汇总双网格 |
| 单据表单 | `/panelx/form/:panelCode` | PanelxForm.vue | 工具栏 + 表头 + 明细子页签 + 表尾 |
| 报表（只读） | 待定（报表页） | （后续） | 查询条件框 + 报表网格 + 导出 |
| 账表（只读） | 待定（账表页） | （后续） | 同上 |

面板配置统一由 `frontend/src/panelx/engine.js` 提供（mock 模式），
`getPanelConfig / getNewFormPermMatrix / getFormDescriptor / queryFormDataList / callButton` 为引擎接口。

## 2. 点击填写（表单交互）标准

### 2.1 表头字段
- 布局：3 列网格（`.fields`），字段按配置顺序排列
- 字段类型映射（`dataType`）：
  - `文本` → el-input
  - `小数/整数` → el-input-number（无步进按钮）
  - `下拉框` → el-select（filterable + allow-create + clearable）
  - `日期` → el-date-picker（YYYY-MM-DD）
  - `是否` → el-switch
  - `图片` → el-image（无图显示"图"占位）
- 必填：label 后红色 `*`（`isRequired`），保存前校验（`validate()`）
- 自动编码字段（`autoCode`）：新增时引擎预填（如 RK-2026-08-0001），表单内**只读**
  （仅当表头含「是否手工修改单据编码」勾选时草稿可改——T+ 语义）
- 只读规则：编辑态（`code` 存在）且状态非草稿时全部禁用

### 2.2 表体明细
- 结构：`detail.tabs[]`，每 tab 一个明细网格
- 子页签：每个明细 tab 内固定「明细 / 汇总」双子页签
  - 明细：el-table，可增行/删行（编辑态）
  - 汇总：`summaryItems` 配置的合计项表格
- 列类型：下拉框/是否/图片/小数/文本（与表头一致）
- 计算链：`calc` 配置（如 `金额 = 数量 × 单价`、`含税金额 = 数量 × 含税单价`），
  输入变化实时重算（`applyCalc`，支持四则运算表达式）
- 合计行：数值列底部合计（`summarize`）
- 子表（expand）：`subTable` 配置，展开行维护（如工序材料）

### 2.3 点击填写交互细节
- 输入框统一 `@keyup.enter` 不提交（表单内回车不触发意外保存）
- 明细行删除：编辑态行尾删除图标（红色）
- 选择类字段值变更后立即触发计算链与合计刷新
- 文本超长列 `show-overflow-tooltip`（列表页）

## 3. 弹窗标准

### 3.1 消息反馈
| 场景 | 组件 | 样式 |
|---|---|---|
| 操作成功 | `ElMessage.success('「X」执行成功')` | 顶部绿色 |
| 校验失败 | `ElMessage.warning(msg)` | 顶部黄色 |
| 未实现功能 | `ElMessage.info('演示环境暂未实现「X」，界面与 T+ 保持一致')` | 顶部蓝色 |
| 接口错误 | `ElMessage.error(engine.errMsg(e))` | 顶部红色 |
| 危险确认 | `ElMessageBox.confirm(...)` | 居中确认框 |

### 3.2 确认弹窗
- 删除单据：`确认删除单据 {单据编号}？`（type=warning）
- 新增切换（未保存草稿）：`当前单据尚未保存，切换新增将丢弃修改，是否继续？`
- 未实现按钮：一律 info 提示，不阻塞页面

### 3.3 拉式选单弹窗（配置驱动，核心交互）
- 入口：工具栏「选单」组（表单页）或列表页「选单」按钮
- 前提：面板配置存在 `selectConfig`；无配置则 info 提示未实现
- 弹窗结构（PanelxForm.vue 统一实现）：
  - 标题：`selectConfig.title`
  - 提示：`selectConfig.tip`
  - 网格列：`selectConfig.columns`（动态渲染）
  - 多选：checkbox 列，底部「确定生单（N 行）」
- 数据来源：`engine.queryFormDataList({ panelCode: selectConfig.source, condition: { 单据状态: '已审核' } })`
  （对齐 T+ 选单前提：已审核且未中止）
- 确认带入：
  - 表头：`selectConfig.headerMap[]`（from 来源字段 → to 当前表头字段；fixed 为固定值）
  - 明细：`selectConfig.detailMap[]`（from → to），写入第一个明细 tab
  - 来源单号：`selectConfig.sourceNoField`（未配置时回填「来源单据」）
- 带入后：`applyCalc()` 重算 + success 提示行数

### 3.4 配置示例
```js
// 销售出库单 → 选销售订单（engine.js SALE_OUT）
selectConfig: {
  source: 'SO_ORDER',
  title: '选销售订单',
  tip: '仅显示已审核且未中止的销售订单，选中后明细带入销售出库单（对齐 T+ 选单前提）',
  columns: ['单据编号', '单据日期', '客户', '业务员', '预计交货日期', '存货名称', '数量', '销售单位'],
  headerMap: [
    { from: '客户', to: '客户' },
    { from: '结算客户', to: '结算客户' },
  ],
  detailMap: [
    { from: '存货名称', to: '存货名称' },
    { from: '存货编码', to: '存货编码' },
    { from: '销售单位', to: '计量单位' },
    { from: '数量', to: '数量' },
  ],
}
```

## 4. 工具栏标准

- 分组渲染：`buttonGroups[]`（name + actions），主按钮 + 下拉（多动作时）
- 快捷键提示：`SHORTCUTS`（Alt+S 保存 / Alt+\\ 保存新增 / Alt+G 保存打印 / Alt+P 直接打印 / Alt+Z 放弃…）
- 按钮可用性（`isDisabled`）按单据状态：
  - 保存/保存新增/保存为草稿：仅草稿可编辑
  - 删除：仅草稿
  - 审核：草稿→已审核；弃审：已审核→草稿
  - 中止执行/整单中止：已审核/生产中/已完工
  - 草稿（恢复）：已中止
- 未实现按钮：engine `UNIMPLEMENTED` 集合，点击 info 提示（界面照 T+ 展示）

## 5. 列表页标准

- 查询区：`queryFields` 配置驱动，3 列网格，查询/重置按钮
- 网格：明细/汇总双子页签；右键菜单（定位/复制到剪贴板/另存为EXCEL模板/批量修改/…/更多）
- 行双击/操作列「查看」→ 表单页
- 行内新增（`新` 图标）→ 行内编辑保存
- 分页：10/20/50 条

## 6. 新增面板接入清单（后续所有设计面板沿用）

1. `engine.js`：新增面板配置（复用 `invPanel` 工厂或同构对象），注册进 `panelOf` 注册表；
   如需选单补 `selectConfig`；如需推式生单在 `callButton` 加分支
2. `engine.js`：演示数据加入对应 `*_SEED`（或独立数组），`flattenFor/nextNoFor` 注册
3. `menus.js`：菜单挂 `panelCode`（path 形如 `/panelx/list/XXX`）
4. 报表/账表类：沿用查询框 + 只读网格 + 打印/导出/发送邮件工具栏（T+ `/v2/bap/report` 形态）
5. 交互零新增：点击填写/弹窗/选单全部由 PanelxList/PanelxForm 通用组件承载

## 7. 与真实 T+ 的对齐要点

- 选单前提：仅已审核且未中止的来源单据（实测 SA03 语义）
- 自动编号：单据编号 = 前缀-年-月-流水（RK/CP/IC/IO/MD/ID/…，实测 T+ 规则）
- 表尾：制单人/审核人/审核日期/审核时间/打印次数/修改人/变更人/变更日期（配置或组件默认）
- 未实现项提示文案统一：「演示环境暂未实现「X」，界面与 T+ 保持一致」
