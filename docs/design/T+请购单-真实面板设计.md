## 2. 新增表单（点击「新增」后 DOM 实测）

### 2.2 明细列（与列表页一致，见 1.2）

### 2.3 选单/生单规则（对齐 T+）

- **选单前提**：选销售订单 / 选预测单 / 选采购计划（已审核未中止）
- **生单**：生成采购订单（PU01→PU02）、生成询价单
- 批量：请购单批量生采购订单（#TOPBGVPU01toPU02）

### 2.4 业务规则（T+ 语义）

- 单据日期 = 登录日默认；单据编号自动（PU 日期序号）
- 请购人默认当前操作员
- 明细：存货必填、数量必填；单价/含税单价/金额/含税金额 计算链（税率%）；智能推荐可带建议供应商
- 审批流：草稿 → 提交审批 → 审批中 → 通过(已审核)/驳回(草稿)（对齐项目审批面板通用逻辑）

## 3. 开发对照（本项目面板配置要点）

- 面板码：`PU_REQ`（对齐现有面板命名，如 PU_ORDER 采购订单）
- category：单据；审批面板（APPROVAL_PANELS 按需加入）
- 列表查询字段：10 个（1.1）；gridTabs columns：1.2 可见列
- 表头 fields：2.1 可见字段（必填 * 转 isRequired:true；日期/参照/下拉按 dataType）
- 明细 tabs：`{ key:'items', label:'明细', summaryItems:[数量合计,金额合计,含税金额合计], calc:[含税单价=单价*(1+税率%/100), 金额=数量*单价, 含税金额=数量*含税单价], fields: 1.2 列 }`
- 工具栏 buttonGroups：按 1.3 配置；选单 selectConfig：source=SO_ORDER（选销售订单，headerMap/detailMap 按 T+ 映射）；生单「生成采购订单」待开发
