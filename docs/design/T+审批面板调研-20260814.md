## 四、业务含义与启发

1. **审核 ≠ 审批流**：本账套所有单据只有"审核/弃审"环节（HasAuditProcess=True），"审批流"（HasWFAuditProcess）均未启用——"审批情况"按钮（ViewWFProgress）为工具栏固定渲染项，未启用审批流时点击无效/提示未启用。审批流需在「单据设计 → 审批流」中按单据类型配置启用。
2. **生产/汇报类单据强制审核**：生产加工单、工序汇报单、返修工序汇报单 IsNeedAudit=True（未审核不能做后续业务，如 末工序按合格数量自动入库 需审核后触发）。
3. **期初类单据带审核**：期初暂估入库单/期初销售出库单/库存期初余额均有审核环节（对齐 T+ 期初数据需审核后才生效）。
4. **物料清单/工艺路线有审核**：DoubleList 类档案启用审核（BOM/工艺变更需审核发布），普通 BaseInfoList 档案无审核。
5. **对轻MES 的参考**：当前轻MES mock 单据已有 审核/弃审 状态机（草稿→已审核），与 T+ 一致；若要模拟"审批流"，需在单据设计类面板增加 审批流配置，或对 IsNeedAudit=True 的单据（生产加工单/工序汇报单/返修工序汇报单）做 未审核禁止生单 的业务约束。
