## 一、部署架构

```

            ├── /        前端静态页（frontend/dist，VITE_MOCK=false 构建）
```

## 二、本地准备（Windows 开发机）

### 2.1 数据库连接配置（已改）

文件：`backend/src/main/resources/application.yml`，与宝塔数据库账号保持一致：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/little_mes?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: little_mes
    password: "<数据库密码>"
```

| 项 | 原值 | 现值 |
|---|---|---|
| 端口 | 3308 | **3306**（宝塔 MySQL 默认端口） |
| 库名 | light_mes | **little_mes** |
| 用户名 | root | **little_mes** |
| 密码 | <数据库密码> | **<数据库密码>** |

### 2.2 SQL 文件（`backend/src/main/resources/db/`）

| 文件 | 用途 | 何时用 |
|---|---|---|
| `init.sql` | 项目原始脚本（缺角色/部门表、缺报表面板） | ❌ 不直接用 |
| `init_full.sql` | 完整版（库名 light_mes + 28 报表面板） | ❌ 库名不对，不用 |
| `init_little_mes.sql` | 完整版（库名 little_mes + 28 报表面板，含 CREATE DATABASE/USE） | 命令行导入用 |
| `little_mes_import.sql` | 纯库内容版（无 CREATE DATABASE/USE，宝塔选中库导入） | **宝塔导入主文件** |
| `panel_report_config.sql` | 仅 28 个报表面板增量（无建表） | ❌ 只补报表时用 |
| `fix_role_dept.sql` | 结构补丁：sys_user 补 role_id/dept_id + 新建 sys_role/sys_role_panel/sys_dept + ADMIN 角色种子 | **必须导入**（详见 3.2） |

> 报表面板 SQL 由 `tools/gen-panel-sql.mjs` 从 `frontend/src/business/engine.js` 自动生成（28 个面板）。

## 三、服务器部署（Ubuntu 22.04 + 宝塔）

### 3.1 环境准备

```bash
apt update
apt install -y nginx openjdk-17-jdk
java -version          # 确认 17+
```

> 宝塔面板安装 MySQL 8（软件商店安装即可），并创建数据库 `little_mes`（字符集 utf8mb4、本地服务器、账号 `little_mes`，密码使用高强度随机值）。

### 3.2 数据库导入（宝塔，顺序不能错）

**第 1 步：上传 SQL**（本机）：
```powershell
scp D:\PANDA-master\backend\src\main\resources\db\little_mes_import.sql root@服务器IP:/root/
scp D:\PANDA-master\backend\src\main\resources\db\fix_role_dept.sql root@服务器IP:/root/
```

**第 2 步：导入主文件**：宝塔 → 数据库 → `little_mes` → 导入 → 选 `little_mes_import.sql`
（建 8 张表 + 种子数据 + 70 个面板配置；`ON DUPLICATE KEY UPDATE` 幂等，可重复导入）

**第 3 步：导入结构补丁**：同样方式导入 `fix_role_dept.sql`
（sys_user 补 role_id/dept_id 列；新建 sys_role/sys_role_panel/sys_dept；写入 ADMIN 角色并关联 admin 用户）
⚠️ 此文件 `ALTER TABLE` 非幂等，**只导入一次**。

**验证**：
```bash
mysql -ulittle_mes -p little_mes -e "SHOW TABLES;"
# 应显示 11 张表：sys_user sys_menu sys_role sys_role_panel sys_dept factory manu_order manu_order_item panel_config form_data form_approval
```

### 3.3 后端部署

```bash
# 上传 jar（本机）
scp D:\PANDA-master\backend\target\light-mes-backend-0.1.0.jar root@服务器IP:/usr/local/

# 服务器启动（必须加 & 放后台）
cd /usr/local
nohup java -jar light-mes-backend-0.1.0.jar > app.log 2>&1 &

# 等 20 秒后验证
sleep 20 && tail -20 /usr/local/app.log      # 看到 Tomcat started on port 8080
ss -tlnp | grep 8080                          # 端口监听
```

### 3.4 前端部署 + nginx

```bash
# 上传 dist（本机；务必用 tar 打包，勿用 WinRAR）
cd D:\PANDA-master
tar -czf dist.tar.gz -C frontend dist
scp dist.tar.gz root@服务器IP:/var/www/light-mes/

# 服务器解压
cd /var/www/light-mes
tar -zxvf dist.tar.gz && rm -f dist.tar.gz
chown -R www-data:www-data /var/www/light-mes
ls dist/          # 确认有 index.html + assets/
```

nginx 站点配置 `/etc/nginx/conf.d/light-mes.conf`：

```nginx
server {
    listen 80;
    server_name _;
    root /var/www/light-mes/dist;
    index index.html;
    client_max_body_size 200m;

    location / {
        try_files $uri $uri/ /index.html;
    }
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;
    }
}
```

```bash
# 禁用 nginx 默认站点（避免端口冲突）并生效
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

### 3.5 防火墙

- 宝塔面板 → 安全 → 防火墙：放行 **80**、**8080**
- 云服务商安全组：放行 **80**（8080 可只放内网）

## 五、常见问题排查（本次实测踩坑记录）

| 现象 | 原因 | 解决 |
|---|---|---|
| `curl localhost:8080` 返回 403 | Spring Security 拦截未认证根路径，**正常** | 前端通过 `/api/auth/login` 登录即可 |
| 登录报 `Table 'little_mes.sys_user' doesn't exist` | 只导入了 `panel_report_config.sql` 增量，没导主文件 | 导入 `little_mes_import.sql` |
| 登录报 `Unknown column 'role_id'` | 缺 `fix_role_dept.sql` 结构补丁 | 导入 `fix_role_dept.sql`（只一次） |
| tar 解压报 `not in gzip format` | Windows 压缩成了 zip/rar 却命名 .tar.gz | 用 `tar -czf`（Windows 10+ 自带）打包 |
| nginx 500 + `rewrite or internal redirection cycle` | nginx root 目录与解压目录不一致（light-mes vs light_mes） | 统一目录 `/var/www/light-mes/dist` |
| nginx warn `conflicting server name "_"` | 默认站点未删 | `rm -f /etc/nginx/sites-enabled/default` |
| 登录成功但看不到面板 | admin 未关联 ADMIN 角色（role_id 为空） | 执行 fix_role_dept.sql 第 6 步 UPDATE |
| 外网访问不通 | 防火墙/安全组未放行 | 放行 80（宝塔 + 云安全组） |
