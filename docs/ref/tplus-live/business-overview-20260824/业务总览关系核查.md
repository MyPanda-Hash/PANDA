## 生产管理数据流

生产管理页面的“业务流程图”完整渲染后，画布中的节点为：

- 销售订单
- 生产加工单
- 采购需求分析
- 工序汇报单
- 调拨单
- 领料申请单
- 材料出库单
- 产成品入库单

按页面箭头读取到的主关系为：

```text
销售订单 → 生产加工单
生产加工单 → 采购需求分析
生产加工单 → 工序汇报单
生产加工单 → 调拨单
生产加工单 → 领料申请单
领料申请单 → 调拨单
领料申请单 → 材料出库单
调拨单 → 材料出库单
生产加工单 → 材料出库单
生产加工单 → 产成品入库单
```

这张图表达的是生产模块内的业务关系和可追踪流向；右侧“相关单据”是可直接进入的关联入口，并不全部代表严格的先后顺序。

### 生产管理关联档案

存货、计量单位、部门、员工、仓库、项目、班组、工序、工艺路线、物料清单。

### 生产管理关联单据

多阶投产、生产加工单、材料出库单、产成品入库单、销售订单、采购需求分析、请购单、采购订单。

### 生产管理关联报表

生产加工单执行表、生产加工单跟踪工具、生产加工单产成品明细表、生产加工单材料明细表、生产加工单工序明细表、生产加工单产成品统计表、生产加工单材料统计表、生产加工单工序统计表。

## 其他已打开模块

### 委外管理

- 档案：存货、计量单位、往来单位、部门、员工、仓库、项目、班组、工序、工艺路线。
- 单据：多阶投产、委外加工单、委外发料单、委外入库单、委外加工费用单、销售订单、请购单、采购订单。
- 报表：委外发料耗用结存表、委外加工单执行表、委外加工单产成品/材料/费用明细表及统计表。

### 销售管理

- 待办：待审核业务、销售订单待出库业务、销货单待结款业务、销售订单待销货业务。
- 单据链：报价单、销售订单、销货单、销售出库单、销售发票、费用单、销售费用分摊单。
- 报表：销售订单执行表、销货单执行表、销售出库开单执行表、销售毛利分析表、销售排行榜、销售订单跟踪工具、订单毛利分析、客户毛利分析。

### 采购管理

- 单据链：请购单、采购订单、进货单、采购入库单、采购发票、采购费用分摊单、费用单。
- 报表：采购订单/进货单明细表和统计表、请购单执行表、采购订单执行表、进货单执行表。
- 主要方向：请购需求进入采购订单，再进入进货和采购入库；发票、费用分摊用于后续结算核算。

### 配货管理

- 单据：配货单、其他出库单、其他入库单、销售订单、销货单、销售出库单。
- 报表：配货单明细表、配货单统计表、配货综合统计表。
- 关联方向：销售订单/销货单形成配货依据，配货结果关联销售出库或其他出入库。

### 移动仓管与序列号管理

- 移动仓管覆盖采购入库、生产入库、销售出库、材料出库、调拨、其他出入库、盘点、货位调整和库存查询；页面明确给出“入库 → 上下架 → 出库 → 货位调整”。
- 序列号管理覆盖启用存货序列号、入库扫码/录入/导入、出库扫描/选择，以及通过序列号状况表和序列号跟踪表进行追溯。
