# 页面开发规范（表头 · 表中 · 表尾 层级结构）

> 本规范是 light-mes 所有 **PanelX 面板列表页** 的统一页面结构标准，按真实 T+（畅捷通 T+ 轻MES）单据页复刻。
> **以后开发/修改任何面板页面，一律先按本规范的层级结构搭骨架，再结合该面板的具体字段（queryFields / gridTabs / detail.tabs / buttonGroups）填充调整。**
> 实现载体：`frontend/src/core/views/PanelxList.vue`（通用渲染器，配置驱动，不写死任何面板字段）。

---

## 一、层级结构总览

一个面板列表页从上到下固定为 4 层（仅单据类才有第 ④ 层表尾）：

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ① 顶部工具栏（灰条 #f5f7fa，下边框 #d0d7e3）                                  │
│    ├─ 左：按钮分组（新增/选单/保存/删除/审核/生单/变更/工具/联查/设置/打印/更多…）│
│    └─ 右：单据翻页 ◁ ◀ ▶ ▷ ＋「第 x/y 张」＋ 单据编号 ＋ 状态徽章             │
├────────────────────────────────────────────────────────────────────────────┤
│ ② 表头字段区（label 在上、输入框在下；2 行；宽 160px；回车即查询）              │
│    字段来源：tablePages[0].queryFields（单据类用单据头字段）                   │
├────────────────────────────────────────────────────────────────────────────┤
│ ③ 表中 · 明细区块（一个明细一个区块；只一个明细时不拆区）                        │
│    ┌─ 页签头：明细页签（高亮=白底蓝字粗体）＋ 汇总页签(如有) ＋ 右侧图标行       │
│    └─ 表格：明细数据行 ＋ 底部合计行（show-summary）                            │
│       汇总页签：按存货/产品/材料分组行 ＋ 合计行（不重复加表尾合计）             │
│    区块拆分规则：                                                            │
│    ├─ detail.tabs 有 1 个 → 只有 A 区（如 销售订单/出入库单/工序汇报单）       │
│    └─ detail.tabs 有 ≥2 个 → A 区=第 1 个明细，B 区=其余明细                   │
│        （如 生产加工单：A=产成品明细，B=材料明细/工序明细）                     │
├────────────────────────────────────────────────────────────────────────────┤
│ ④ 表尾（仅 panelCategory='单据' 或存在 detail.tabs 时显示）                    │
│    ├─ 备注：文本输入（绑定当前单据，可编辑）                                   │
│    ├─ 分隔线（1px #ccc）                                                      │
│    └─ 审核行：制单人 / 审核人 / 审核日期 / 审核时间 / 打印次数 / 创建时间        │
└────────────────────────────────────────────────────────────────────────────┘
```

## 二、配置 → 页面 映射表（配置驱动，不写死）

| 页面要素 | 配置来源 | 说明 |
|---|---|---|
| ① 左·按钮分组 | `metadata.buttonGroups` | 每组 name + actions，带 caret 的组显示 ▼ |
| ① 右·翻页/单据信息 | 列表查询结果 | 当前单据 = 当前翻页行；状态徽章取 `单据状态` |
| ② 表头字段区 | `tablePages[0].queryFields` | label 在上、控件在下；下拉/日期/文本按 `dataType` 自动选控件 |
| ③ 页签头 | `gridTabs[].label` ＋ `detail.tabs[].label` | A 区优先 gridTabs；B 区取 detail.tabs[1..n] |
| ③ 表格列 | `gridTabs[0].columns`（A 区）/ `detail.tabs[i].fields`（B 区） | 列宽按字段类型推算（见 §四） |
| ③ 汇总页签 | `gridTabs[1].summary` 或 `detail.tabs[i].summaryItems` | 分组键取 编码/名称 列；数值列求和 |
| ③ 合计行 | 明细视图自动 show-summary | 数值列求和，合计字体加粗 |
| ③ 图标行 | 固定两套：A 区 = 产成品风格，B 区 = 材料风格（含现存量提取） | 复制/另存EXCEL 作用于当前区块 |
| ④ 表尾 | 当前单据行字段 | 备注可编辑；审核行取值不存在时留空 |

### 数据契约（关键！）
- **单据类面板**（panelCategory='单据'）的列表查询必须返回 **单据级行**，行内带 `detail` 对象：
  `{ 编号, 单据状态, ...表头字段, detail: { <tabKey>: [明细行...], ... } }`
  `detail` 的 key 必须与 `detail.tabs[].key` 一致（如 products / materials / processes / items）。
- **档案/报表类面板**返回平铺行即可，页面自动把当前行当作明细展示（flatRow 兜底）。
- 列表查询入口：`engine.queryFormDataList`（mock 分支对单据类面板直接返回 `panelOf(panelCode).rows` 并浅拷贝 detail 数组）。

## 三、交互约定（所有页面一致）

1. **单据翻页**：◁ 首页 / ◀ 上一张 / ▶ 下一张 / ▷ 末页；翻到边界自动跨页加载。
2. **表头字段查询**：回车（输入框）、change（下拉/日期）、清空即触发搜索，搜索后回到第 1 张。
3. **右键菜单**（明细表格）：定位 / 复制到剪贴板 / 从剪贴板粘贴 / 另存为EXCEL模板 / 批量修改 / 销售订单查询 / 存货中心 / 更多——复制与另存作用于**当前活动区块**。
4. **双击明细行** → 打开该单据的表单页（`/panelx/form/<panelCode>?code=...`）。
5. **工具栏按钮**：新增→弹窗新建；删除/审核/弃审/生单 等作用于当前单据（配置驱动，未实现项给「界面与 T+ 保持一致」提示）。
6. **合计行**：明细视图底部合计（数值列求和、四舍五入 2 位）；汇总页签 = 分组行 + 合计行（合计行高亮底色 #f7f9fc + 加粗）。

---

## 四、通用规则

- **列宽**：按字段 dataType 推算——是否 74 / 图片 56 / 小数·整数 104 / 日期 136 / 文本按 label 长度（96~220）。
- **表头底色**：`#f7f9fc`；表格边框 `#ddd`；页签高亮 = 白底蓝字粗体 + 1px #ccc 边框。
- **颜色**：工具栏 `#f5f7fa`（边框 `#d0d7e3`）；必填红星 `#FF0033`；主色蓝 `#0d5bd3`；状态徽章：已审核/已完工=绿、生产中=蓝、草稿=橙。
- **横向滚动**：列多时表格横向滚动（同 T+），列内容超宽用 tooltip。
- **布尔/图片列**：演示环境按文本/占位展示即可，不阻塞页面。

## 五、开发/修改一个面板页面的步骤（Checklist）

1. **定面板类型**：单据（有表头+明细+表尾）还是 档案/报表（工具栏+查询+单表格）。
2. **写配置**（engine.js 对应面板 config）：
   - `metadata.panelName / panelCategory`（单据 / 基础档案 / 报表）
   - `tablePages[0].queryFields`（表头字段，带 dataType/options/ref）
   - `tablePages[0].gridTabs`（A 区列 + 是否汇总）
   - `detail.tabs[]`（明细：key/label/fields/summaryItems/calc，参照字段配 ref）
   - `metadata.buttonGroups`（工具栏分组）
3. **给数据**：单据类 `rows` 必须带 `detail`（key 与 tabs 一致）；档案/报表类平铺行。
4. **验证**：`node tools/tplus-grab/verify.cjs --url http://localhost:5173/#/panelx/list/<PANEL_CODE>` 逐页签核对行数/合计；`shot.cjs` 截图目检。
5. **回归**：`npm run build` 通过；对照真实 T+ 截图（tools/tplus-grab）核对列序与页签。
