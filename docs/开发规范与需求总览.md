# 轻MES 开发规范与需求总览

> 本文档为项目全部开发规范与需求的**一站式索引与速查**，详细内容以各规范文档为准（见 §五 文档索引）。
> 最后更新：2026-08-19

## 一、项目概览

- **定位**：参照畅捷通 T+ 门户形态的网页端轻量 MES（生产制造执行系统）。
- **技术栈**：Vue3 + Element Plus + Pinia + Vue Router（前端）｜Spring Boot 3.5 + MyBatis-Plus + MySQL + JWT（后端）。
- **数据源模式**（前端 `core/env.js` 环境变量切换；2026-08-20 起仅两模式，Mock / PanelX 直连已移除）：
  | 模式 | 环境变量 | 说明 |
  |---|---|---|
  | 本地后端（默认） | `VITE_PANELX_PROXY` 空 | `/api` 代理 → Spring Boot（8080）+ MySQL（3308） |
  | PanelX 后端代理 | `VITE_PANELX_PROXY=true` | 后端网关直连平台（token 不落浏览器）；门户壳仍走演示数据 |
- **开发环境**：Node v24 / JDK（build.bat 自动探测）/ 便携 Maven 3.9.9（`tools/`，阿里云镜像 `tools/settings.xml`）。
- **运行**：前端 `cd frontend && npm run dev`（5173，mock 演示账号 admin/123456）；后端 `backend/build.bat && backend/run.bat`（8080）；一键启动 `start-project.bat`（MySQL 3308 + 后端 8080 + 前端 preview 4173）。
- **目录结构**（`frontend/src/`）：
  ```
  core/      通用引擎层（跨项目复用，禁止 import 业务）：env/request/sdk/panel-engine + views 引擎视图
  business/  业务层：engine.js（面板接口 + 平台映射）/ api.js / menus.js
  layout/    门户壳：TopBar / LeftNav / TabsBar / NoticeCenter / HelpPanel / InitWizard
  views/     业务页面：login / dashboard / modules（看板/返修台/方案中心）/ sys（组织架构）
  stores/    user（业务）/ tabs、app（通用）
  router/    路由 + 守卫（isLogin / requireAdmin）
  ```

## 二、开发规范（速查汇总）

### 2.1 架构分层规范（详见 docs/架构分层.md）

- 依赖方向单向：`business → core`、壳层 → business/core，**core 禁止 import 业务**。
- 新面板 = 配置（business/engine.js 或后端 panel_config 表），页面组件零改动；面板注册表 `panelOf` 分发链：BASE_CONFIGS → ROUTE/BOM → INV_CONFIGS → SO/MO。
- 维护规则：业务代码禁止写进 core；任何改动验证 = 前端 `vite build` + 后端 `mvn package`。
- 抽包路线：Phase 1 已分层（别名 `@core`）；Phase 2 core 抽独立包；Phase 3 配置外部化。

### 2.2 页面结构规范（详见 docs/页面开发规范.md）

面板列表页固定 4 层（仅单据类有第 ④ 层）：

```
① 顶部工具栏（灰条 #f5f7fa）：按钮分组（name+actions，点组名=执行首 action，>1 显示 ▼ 下拉）
   右：单据翻页 ◁ ◀ ▶ ▷ + 第 x/y 张 + 单据编号 + 状态徽章
② 表头字段区（label 上、输入框下；2 行；宽 160px；回车即查询）← tablePages[0].queryFields
③ 明细区块（gridTabs/detail.tabs）：页签 + 表格固定 5 行 + 合计行 + 汇总页签
④ 表尾（仅单据类，sticky 底部）：备注（可编辑）+ 审核行（制单人/审核人/审核日期/审核时间/打印次数/创建时间）
```

- **数据契约**：单据类列表查询返回单据级行 `{编号, 单据状态, ...表头, detail:{<tabKey>:[明细行]}}`；档案/报表类平铺行。
- **配置契约**：`buttonGroups[{name, actions}]`（禁止 items/caret 别名）、`gridTabs[{label,rowSource,columns,summary}]`、`detail.tabs[{key,label,fields,summaryItems,calc}]`（key 与 detail 键一致）、`queryFields`。
- **交互约定**：表头查询回车/change/清空即搜；右键菜单（定位/复制/另存EXCEL/批量修改）；双击明细行开表单；固定 5 行 + 占位行；表尾 sticky；列宽按 dataType 推算（是否 74/图片 56/数值 104/日期 136/文本 96-220）。
- **单单据面板**（13 个：EMP/DEPT/INV_PRICE/EQUIP/WC/OP/WH/REGION/PROJ/UOM/REJECT/ROUTE/BOM，详见 页面开发规范 §八）：`metadata.singleDoc=true`、dataSchema.fields 只留单据头、明细全放 detail.tabs、gridTabs 列=明细行字段、只允许 1 张 form_data（form_no=面板名）、保存=整张明细覆盖写回、编号=最大序号+1 查重。

### 2.4 开发约束（强制，详见 工作记录.md §十一）

1. **字段引用基础数据**：语义上对应基础档案的字段必须用「参照字段」（`dataType:'参照'` + refPanel/refField/displayField/filter/refMap/refColumns/refMulti）；仅基础档案无对应语义时才允许手写 options（需注释说明）。引用登记表见工作记录 §十一-1（DEPT/EMP/PARTNER/INV/OP/WC/EQUIP/TEAM/WH/UOM/PROJ/REGION/REJECT/ROUTE/BOM）。
2. **面板注册**：每单据=独立面板（panel_config + form_data + 独立路由 + 单号前缀）；新面板注册进 `panelOf`；禁止组件内按 panelCode 硬编码业务分支。
3. **对齐真实 T+**：新模块开发前先实测真实 T+ 抓结构存档 `docs/ref/tplus-live/`；未实现按钮保留 UI 提示「演示环境暂未实现」；种子数据与既有面板联动（CP001-005/PX001-007/KH001-005 等）。
4. **并行开发**：engine.js/PanelxList.vue 等共享文件可能多会话并发修改，改前读最新、写入校验唯一性、禁止覆盖他人未提交修改。
5. **界面风格**：严禁卡通/emoji/动画装饰；T+ 专业商务风；文案中性。

### 2.5 验收与测试规范

- 每个功能改动必须过 **E2E**（无头 Edge 9223 + localhost:5173，CDP 脚本），关键流程截图存档 `docs/ref/mes-live/`。
- 前端改动 `node --check`（js）+ `vite build`（vue）；后端 `mvn package`；不通过不提交。
- 面板配置三端一致：`panel_config` 表（DB 为最终来源）↔ init.sql ↔ 引擎接口（2026-08-20 前端 mock 配置已移除，不再存在前端种子）。
- E2E 登录注入要点：CDP 注入 localStorage 后必须导航「带 query 的 URL」强制整页加载；真实模式需注入真实登录 token（假 token 会 401 自动登出）。
- 涉及中文数据的自动化写操作与诊断一律用 Node 脚本（PowerShell 中文经管道/HTTP 会编码污染）。

### 2.6 工具与流程

- **T+ 真实面板抓取**：`node tools/tplus-grab/grab.cjs --login --url <Voucher.aspx URL> --name xx --out docs/ref/tplus-live/xx`（产物 dom.json/png/html；会话存 profile/）。

## 四、历史事故红线（BUG 速查，详见 docs/BUG总结.md）

1. **批量替换事故（f→r）**：PowerShell 数组嵌套展开导致 12 文件 800+ 处 f→r；修复=单词级映射+逐轮构建+产物对比。教训：批量替换禁止「数组套数组」；改前 git 提交。
2. **编号 COUNT 法撞号**：EMP 导入 Duplicate entry（COUNT+1 与断号冲突）；修复=最大序号+1 查重循环。**编号生成一律禁止 COUNT 行数法**。
3. **单单据 gridTabs 列配错**：列配成单据头字段→明细预览全空→保存整张覆盖丢数据。**渲染异常时禁止保存**。
4. **汇总分组行数值翻倍**：先复制首行再累加同字段。聚合前先清空待聚合字段。
5. **保存清空明细**：列表页保存仅传 {编号} 时 detail 被 toJson(null) 覆盖。明细兜底=未传 detail 保留原数据。
6. **ElSelect 无限递归**：查询区参照字段每次渲染新建选项数组。选项按列缓存。
7. **ESM re-export 悬空**：`export ... from` 不创建本地绑定。文件内部要用需显式 import。
8. **页签丢 query**：生单后切页签数据丢失。页签=path+query，切换禁止只 push path。
9. **选单只能选第三张单/表单页选单不可用**：接口须返回 selectConfig；?select=1 需 watch payloadCache。
10. **PowerShell 中文/特殊字符污染**：写操作与诊断一律 Node 脚本；mysql 加 --default-character-set=utf8mb4。
11. **MySQL JSON path 不支持中文键**：JSON_SEARCH 需全文档搜索（如 EMP 脏行清理）。
12. **CDP 会话坑**：evaluate 超时竞速 + 点击 fire-and-forget + 轮询重试；登录注入后必须整页加载（带 query 导航）；真实模式假 token 401 自动登出。
